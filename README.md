## 役割分担（導線の設計）

- **単独サイト＝「引く場所」**：辞典型は毎日開くものではなく、「知りたい時に引く」もの。検索で来た人が、目的のページにまっすぐ着ける受け皿にする。
- **森と講座＝「毎日触れる場所」**：集まれ水女子の森（カレンダー等の毎日コンテンツ）と陰陽講座の投稿が日常の入口。昇格後も、森・投稿から単独サイトへの導線は残す。
- このトップ（index.html）からは、森へ戻るリンクと、たけちゃんリンク（全部の窓口）へのリンクだけを置く（雛形に実装済み）。

## 昇格の目安（2026-11-23、たけちゃんと合意。MEMORY.md 記載）

量より「入口の種類」で決める。昇格サインは3つ——

1. 編が増えて森の親カードに収まらなくなった時
2. 講座投稿・note記事など外からの直接の入口が増えた時
3. 「陰陽メガネ」の名前で覚えられる段階になった時

当面は森の中で育て、講座が第2部（練習編）に入って編が増え始めたら昇格を検討する。
